# Phase 5 Images

This folder contains evidence from Phase 5 of the project: heartbeat detection, R–R interval measurement, and heart-rate calculation using the MAX30003 ECG sensor.

## Planned Evidence

- `phase-5-bpm-serial-monitor.png` — Serial Monitor showing stable BPM and R–R interval readings
- `phase-5-bpm-comparison.jpeg` — Prototype compared with a fingertip pulse oximeter
- `phase-5-testing-notes.jpeg` — Written results from repeated comparison trials

The complete breadboard hardware setup is already documented in the Phase 4 image folder and does not need to be duplicated here.

## Privacy and Safety

Photographs should not display personal identifying information. Body-connected ECG testing is performed while the computer is operating on battery power with the charger disconnected.

The heart-rate measurements are experimental and are not intended for medical diagnosis or emergency decision-making.
