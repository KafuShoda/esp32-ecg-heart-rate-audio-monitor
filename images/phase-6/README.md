# Phase 6 Images

This folder documents the integration of the MAX30003 heart-rate measurement with the OLED display.

## Evidence

- `phase-6-live-bpm-oled.jpeg` — OLED displaying live BPM and R–R interval
- `phase-6-oled-serial-comparison.jpeg` — Comparison between the OLED and Serial Monitor
- `phase-6-acquiring-screen.jpeg` — Initial acquiring state

The displayed BPM is an experimental estimate and is not intended for medical use.
