# Hardware Components

## Primary Components

| Component | Function |
|---|---|
| ESP32-based Nano microcontroller board | Runs the embedded program and controls the ECG, display, timing, and audio systems |
| ProtoCentral MAX30003 ECG breakout | Acquires a single-lead ECG signal and provides heartbeat information |
| 1.3-inch 128x64 OLED display | Displays BPM, heart-rate zone, signal status, and audio status |
| DFPlayer Mini | Plays prerecorded audio files stored on a microSD card |
| MicroSD card | Stores the audio files used by the DFPlayer Mini |
| Mono earpiece | Provides audio feedback through one ear |
| 3.5 mm jack breakout | Provides an accessible connection for the earpiece |
| ECG electrodes | Create electrical contact between the body and ECG sensor |
| Breadboard | Allows temporary circuit construction without soldering |
| Jumper wires | Create electrical connections between the modules |
| USB-C data cable | Provides power and enables program uploading |
| USB power bank | Provides portable power during later testing |

## Development Tools

- Windows computer
- Arduino IDE
- Digital multimeter
- Soldering tools for later prototype construction

## Current Prototype Type

The current system is a solderless breadboard prototype. The modules are being tested independently before they are integrated into one complete system.
